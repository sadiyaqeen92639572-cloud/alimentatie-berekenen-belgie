# Alimentatie Berekenen België

Gratis rekentool voor alimentatie in België, gebaseerd op de officiële **methode Hobin/IGAK** — de rekenmethode gebruikt door de meerderheid van de Nederlandstalige familierechters.

Berekent automatisch de bijdrage van elke ouder op basis van netto inkomens, aantal en leeftijd van de kinderen, en de verblijfsregeling.

**Site:** [alimentatie-berekenen.be](https://alimentatie-berekenen.be)

**Franstalige zustersite:** [calculateur-pension-alimentaire.be](https://calculateur-pension-alimentaire.be)

## Free Companion Tools

- [IGAK Percentage Opzoeken](https://sadiyaqeen92639572-cloud.github.io/igak-percentage-tabel/) — snel het officiële IGAK-percentage opzoeken per leeftijd, aantal kinderen en gezinsinkomen. Powered by alimentatie-berekenen.be.

---

Bron methode: officiële rekentool kinderalimentatie, gepubliceerd door de Belgische hoven en rechtbanken (rechtbanken-tribunaux.be).
